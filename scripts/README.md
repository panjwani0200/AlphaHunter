# Scripts

Developer and operations scripts live here.

## Backend

Start local backend and dashboard:

```powershell
.\scripts\start_backend.ps1
```

Stop local backend:

```powershell
.\scripts\stop_backend.ps1
```

Prepare PostgreSQL:

```powershell
.\scripts\setup_database.ps1
```

Check runtime readiness:

```powershell
.\scripts\check_readiness.ps1
```
