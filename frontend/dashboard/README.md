# AlphaHunter Dashboard

This folder contains the local dashboard MVP served by FastAPI from `frontend/dashboard/public`.

The long-term direction remains Next.js for SaaS readiness, authenticated user workflows, real-time views, and a richer operational interface. The current static dashboard keeps the V1 runnable without introducing a second build chain too early.

Planned tabs:

- Market Overview
- Stock Lookup
- Scanner
- Open Trades
- Alerts Feed
- Historical Analytics
